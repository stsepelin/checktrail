# Independent evaluation setup acceptance

The nine frozen `independent-evaluation-protocol` callbacks exercise the connected
operator pipeline with original synthetic inputs. They do not run a model review,
acquire held-out source or answers, or measure review quality.

Broken, repaired and valid adjacent examples run a native Node predicate against
the exact source bytes supplied to the anonymous judging packet. Captures,
separate judgments and common-defect mappings feed both paired comparisons,
retaining all selected cases, repetitions and incident clusters. The examples use
synthetic external declarations and scripted responses; they do not attest actual
review-host independence, label authority, configuration authenticity or billing.
Those limitations remain explicit in every score report.

The other controls reject unavailable prerequisites and changed source, keep
empty and malformed outputs in the denominator, and exercise library and operator
CLI disclosure grants. A real MCP client verifies execution arguments cannot
supply operator trust; the private comparison archive remains outside its root.
Reached native collector cancellation, deadline and output exhaustion controls
retain bounded physical bytes, verify owned descendants terminate, and preserve
failed attempt/unknown usage accounting. Replay uses the sealed bytes after the
incoming inbox is removed. No interrupted host review is resumed automatically.

Run the required source callbacks after building:

```sh
node scripts/verify-required-native-tests.mjs independent-evaluation-protocol
```

The installed callback repeats the same required file against a fresh offline
production installation. Its harness and pinned external SDK client stay outside
the installed package; lifecycle scripts remain disabled. It checks compiled
engine identity and unchanged harness/runtime bytes before and after execution.
The directly callable equivalent is:

```sh
node scripts/verify-evaluation-protocol-package.mjs --whole
```

Local development runs do not qualify the eight selected runtime slots. Final
runtime receipts, the private prospective setup and remaining inventory freeze
decisions are still required before this profile or Gate A can close. Public
fixtures are already inspected development material and cannot become held-out
comparison cases by changing an identifier.
