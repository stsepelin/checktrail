# Selected C source context

Opt-in context version 20 uses the existing pinned C WASM grammar over captured strings. The shared engine, CLI and MCP retain whole functions and decisions, declaration initializer addresses, literal constant reads, exact ASCII names and bounded callers under explicit disjoint source roots. Capture invokes no compiler, preprocessor, initializer, build file or project configuration. Versions 1–19 retain their contracts.

The supported subset is plain functions with primitive return types, ordinary parameter/declarator names, literal file constants, ordinary nested compound blocks and quoted relative `.h` include candidates. Names enter scope at their declarator, including before their initializer; parameters and local values mask direct-function candidates. An include contributes selected declarations only after its captured include site. Arbitrary neighboring `.c` files contribute no declarations. Repeated definitions or includes remain ambiguous.

A selected quoted header is a captured candidate, not proof of native include search or a compiler translation unit. Include traversal stops at eight levels, 256 visits or 4096 contributed declarations. Unselected headers can define macros and therefore leave dispatch unknown. Preprocessor directives, line splicing, header guards, system/macro includes, prototypes and linkage, unsupported scopes/types/attributes, indirect/member calls, build selection and ABI remain explicit unknowns. Caller depth is eight; full impact fallback and unchanged validation planning are mandatory. A function-pointer factory retains distinct inner and outer call ranges; the outer indirect call stays unresolved.

Original synthetic Linux ARM controls use Node 22.23.2 and the fixed parser. Supplementary GCC 14.2.0 witnesses from the pinned tool image compile the broken, repaired and valid boundary examples and a fork/reap lifecycle worker. They do not promote native name resolution, general C compilation or runtime reachability. Installed acceptance uses the same callbacks through an offline production installation. Optional unavailable host checks are reported as skips. Parser bytes and source identity are already in the grammar manifest; full native artifact/notice closure and final release acceptance remain separate Gate A obligations.

Declaration and function display names are bounded to 256 UTF-16 code units. Valid longer names retain complete source ranges with null display names and explicit unknown binding metadata; they cannot abort context capture. Original boundary fixtures and compiling guard controls exercise the supported and first unsupported lengths in source and fresh installed acceptance.
