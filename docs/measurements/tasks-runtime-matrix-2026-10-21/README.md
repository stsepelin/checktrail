# Selected Tasks runtime observations

These receipts come from the successful main workflow [39626059097](https://github.com/stsepelin/checktrail/actions/runs/39626059097) at source commit `fcf1344ad43b586e9504ade1587f33d3d24575df`. The [observation record](observations.json) binds each exact job, selected runtime, retained packet body and source/install case ledger. It covers all six selected Linux/macOS Node slots, the selected Windows slot and the pinned Linux ARM64 container. These are original synthetic validation and Tasks cases; no AI inference or field review ran.

The source and fresh offline installation receipts retain 390 reconciled terminal case results. Each non-Windows run requires 24 named callbacks; Windows requires 27, including native caller-only ACL and SQLite journal controls. Required events, file identities, sequence links, unchanged compiled runtime/harness bytes and exact Node/platform/architecture fields were checked. Changed Node identity, failed or missing events, stale harness/compiled bytes, foreign cases and empty required accounting were rejected by paired controls; the original packets remained valid.

The JSON files in `receipts/` preserve the original packet bodies after removing GitHub timestamp prefixes, followed by one LF. The ARM64 file preserves its source/install container envelope. Raw full job logs remain separate; their byte counts and digests are recorded. Hosted image version/OS metadata and Node executable hashes are observations, not signed OS-image attestations. Reported installed tarball and production-lock identities are retained; those tarballs were not independently reconstructed during this reconciliation.

The named cases and byte-comparison recipe are in the recorded source commit, including `scripts/tasks-runtime-evidence.mjs`, `scripts/verify-tasks-runtime-package.mjs` and `scripts/verify-tasks-runtime-arm64.mjs`. The receipts qualify their recorded source and selected Tasks foundation only. They do not qualify later dependency/source changes, every native adapter, durable archive profiles, model-host interoperability, review quality or the whole Gate A matrix. Gate A remains open.
