# Whole attempt-archive acceptance

The `attempt-archives` profile exercises broken, repaired and valid near-miss
programs, prerequisite refusal, source freshness, empty/skipped bodies, privacy,
operator trust, cancellation and fresh installed-package behavior. Its original
synthetic workspace executes two distinct consumers of the same producer.
Receipts reconcile physical journal bytes, actual child identities and outcomes.
The storage control closes and reopens a Tasks store and reconstructs the exact
oversized report and journal from bounded chunks.

`scripts/verify-attempt-runtime.mjs` requires the complete selected profile
from source and a fresh offline production installation. Its external harness
binds the source files, callback requirements, package and production dependency
lock, observed runtime and compiled engine bytes. A separate foundation ledger
preserves the original journal codec, private storage, streaming invocation,
wrapper catalog, physical output and scripted API-attempt controls. Missing,
duplicate, extra, skipped, stale or inconsistent receipt entries fail admission.
Windows records the sole ordinary POSIX descendant control as excluded; native
POSIX slots retain it. On Windows, where held files can block a directory move,
the replacement controls inject one cleanup refusal to release the descriptors,
then physically replace the directory and verify that identity checks still reject
collection and deletion. POSIX controls replace the directory with descriptors held.
Scripted API controls contact no provider.

A pinned Go 1.27.1 executable runs the physical archive control. Its version,
target and executable digest must remain unchanged across both cohorts. The
Windows Go control supplies a private operator cache outside project source; the
runner does not inherit ambient `LocalAppData`. The
controller observes the tool and does not install it. Hosted jobs provision the
exact version; the ARM controller verifies the native Linux ARM64 Go tree and
mounts it read-only into the pinned container. The image supplies Git. Host image
metadata and container identities are observations, without host attestation or
complete upstream producer-build qualification.

The shared named-profile runner gives `attempt-archives` the same fresh callback
processes and 600-second collection allowance as the dedicated controller.
The Windows installed callback has a 20-minute outer observation allowance for
its complete fresh profile, original foundation and package setup; its child
collector has ten seconds less. The shared runner grants this allowance only to
the exact isolated installed callback. Other individual callback deadlines and
production execution/cleanup limits remain unchanged. CI runs source and installed cohorts in separate required jobs for the selected
runtime slots and a pinned Linux ARM64 controller. The [historical hosted
measurement](measurements/attempt-archives-hosted-2026-11-01.json) qualifies eight
source/fresh runtime pairs at the exact recorded c25 source and compiled harness.
Historical receipts are not relabelled. The [main-source measurement](measurements/attempt-archives-hosted-2026-11-16.json)
reconciles eight source/fresh pairs at main commit
`6809bf39c3aba1f1b582742c741051667461754e` from run `43635572499`.
The existing strict validators matched all original direct and foundation
terminal events, pinned native tool observations, physical archive controls and
fresh production-install bindings against that recorded source and rebuilt
engine/harness bytes. The explicit Windows POSIX exclusion remains an exclusion,
and contributes no POSIX acceptance credit.

[The development measurement](measurements/attempt-archives-development-2026-10-28.json)
records successful source and fresh-install execution on the observed current
Mac. No final runtime slot was selected, so it does not satisfy the frozen
runtime matrix. The later hosted measurements supply that matrix only at their
recorded sources; changed revisions need their own binding. Full artifact/build/license
closure, independent evaluation and Gate A remain open. No inference or field
evaluation ran.
