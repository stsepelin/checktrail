# Whole attempt-archive acceptance

The `attempt-archives` profile exercises broken, repaired and valid near-miss
programs, prerequisite refusal, source freshness, empty/skipped bodies, privacy,
operator trust, cancellation and fresh installed-package behavior. Its original
synthetic workspace executes two distinct consumers of the same producer.
Receipts reconcile physical journal bytes, actual child identities and outcomes.
The storage control closes and reopens a Tasks store and reconstructs the exact
oversized report and journal from bounded chunks.

`scripts/verify-attempt-runtime.mjs` requires the complete selected profile
from source and a fresh offline production installation. Its external harness
binds the source files, callback requirements, package and production dependency
lock, observed runtime and compiled engine bytes. A separate foundation ledger
preserves the original journal codec, private storage, streaming invocation,
wrapper catalog, physical output and scripted API-attempt controls. Missing,
duplicate, extra, skipped, stale or inconsistent receipt entries fail admission.
Windows records the sole ordinary POSIX descendant control as excluded; native
POSIX slots retain it. Scripted API controls contact no provider.

A pinned Go 1.27.1 executable runs the physical archive control. Its version,
target and executable digest must remain unchanged across both cohorts. The
controller observes the tool and does not install it. Hosted jobs provision the
exact version; the native ARM image supplies its pinned toolchain. Host image
metadata and container identities are observations, without host attestation or
complete upstream producer-build qualification.

The shared named-profile runner gives `attempt-archives` the same fresh callback
processes and 600-second collection allowance as the dedicated controller.
Individual callback deadlines and production execution/cleanup limits remain
unchanged. CI runs source and installed cohorts in separate required jobs for the selected
runtime slots and a pinned Linux ARM64 controller. Those hosted runs remain
unverified until observed.

[The development measurement](measurements/attempt-archives-development-2026-10-28.json)
records successful source and fresh-install execution on the observed current
Mac. No final runtime slot was selected, so it does not satisfy the frozen
runtime matrix. Complete call-family qualification, full artifact/build/license
closure, independent evaluation and Gate A remain open. No inference or field
evaluation ran.
